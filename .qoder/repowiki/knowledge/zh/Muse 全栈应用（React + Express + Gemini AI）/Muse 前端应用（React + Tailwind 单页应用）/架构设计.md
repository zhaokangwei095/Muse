应用采用经典的 React 单文件组件架构：`main.tsx` 通过 `react-dom/client` 的 `createRoot` 挂载根节点；`App.tsx` 作为唯一状态管理中心，集中持有 `currentTab`、`user`、`posts`、`messages`、`bookmarks` 等全局 state，并通过 props 向下分发到各 `views/*` 页面组件；`components/` 存放跨视图复用的 UI 块（Header、BottomNavBar、EditProfileModal）；`data/mockData.ts` 以纯常量形式提供初始数据，替代后端 API；`types.ts` 统一定义 `NavTab`、`User`、`PostItem`、`DirectMessage`、`BookmarkCollection` 等共享类型。路由并非基于 react-router，而是由 `App` 根据 `currentTab` 值进行条件渲染实现简易路由，同时支持 `selectedPost` 作为详情页覆盖层。深色模式通过 `useEffect` 同步 `document.documentElement.classList` 上的 `dark` 类实现。
