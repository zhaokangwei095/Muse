- 所有视图组件以 `*View.tsx` 命名并按功能分目录 `views/` 组织，每个组件通过接口 Props 定义输入，事件回调统一使用 `onXxx` 前缀（如 `onToggleLike`、`onSelectPost`）。
- 共享数据类型集中在 `types.ts` 中用 TypeScript interface/type 声明，组件间通过 import 引用而非重复定义。
- Mock 数据以只读常量形式放在 `data/mockData.ts`，由 `App.tsx` 在初始化时读取并注入到各视图组件中。
- 深色模式通过给 `<html>` 元素添加/移除 `dark` class 控制，组件内使用 Tailwind 的 `dark:` 前缀样式响应主题变化。
- 导航状态由 `App` 中的 `currentTab`（类型为 `NavTab` 字面量联合类型）驱动，子组件仅通过回调向上通知切换，不直接修改父级 state。
