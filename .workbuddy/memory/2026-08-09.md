## Muse 产品功能介绍文档

为 Muse 项目生成了对外产品功能介绍 docx 文件，输出到 `buddy_output/Muse产品功能介绍.docx`。

- 文档结构：六大功能章节（沉浸式灵感探索 / 沉浸式视觉设计 / 创作者聊天 / 灵感收藏 / 塔罗式情绪探索 / 灵感热度速览）+ 文档说明 + 模块关系附录 + 结语
- 每个章节固定四个小节：功能概览、核心交互、设计要点、图片占位区（用户自行插入截图）
- 使用 word-document-processing 技能的标准流程：Markdown → pandoc（律师规范模板 + Lua 过滤器）→ doc_styler 样式化

## 踩坑与解决方案

- word-document-processing 技能的 `scripts-md2docx.py` 期望导入 `scripts_doc_styler.py`（下划线），但实际文件名是 `scripts-doc_styler.py`（连字符）→ 直接复制为下划线文件名绕过，脚本即可正常运行
- python-docx 默认未安装在 managed Python 中，需要先 `pip install python-docx`
- 路径 `./assets/placeholder-*.png` 是不存在的占位符，pandoc 会自动用 alt 文本替代作为占位

## 项目背景速记

- Muse 是一款美学灵感社区 App，PC Web + 移动端 H5 双端自适应，移动端为主体验
- 设计语言：玻璃拟态（Glassmorphism）、蓝紫主色、动效细腻
- 核心模块：发现页 / 探索页（Tinder 式牌堆 + 双模式切换） / 发布 / 消息（AI 私信） / 关注 / 个人主页 / 设置
- AI 嵌入两个场景：创作灵感生成、私信智能回复；都必须配置失败兜底分支
