> Muse ------ 美学灵感社区 App 版本：v1.0　文档生成时间：2026 年 8 月

## **一、沉浸式灵感探索**

  --------------------------------------------------------------------
                           **沉浸式灵感探索**

  --------------------------------------------------------------------

功能概览：以 Tinder 式卡片滑动为核心、瀑布流浏览为辅的"双模式探索体验"。用户通过左右滑动快速筛选灵感内容，遇到心仪的作品可一键进入详情页，或切换到瀑布流模式沉浸式浏览。

核心交互

- 卡片牌堆（默认模式）：顶卡可水平拖拽并轻微旋转，背后下一张卡随拖拽逐渐放大浮现，提供真实的"翻牌"手感
- 双模式切换（移动端专属）：顶部胶囊控件可在"瀑布流 ↔ 卡片滑动"之间无缝切换，切换过程带有淡入过渡动画
- 滑动模式细分（探索页 Like 模式）：右滑 = 喜欢（绿色 LIKE 徽章渐显），左滑 = 跳过（红色 PASS 徽章）；切换为 Next 模式后，左右滑动都只是前进到下一张
- 飞出反馈：每张卡滑出后中央爆发动画反馈 ------ 喜欢显示粉色实心爱心，跳过显示灰色叉
- 底部操作栏：跳过/上一张、查看文章、私信作者、喜欢/下一张（主色大圆钮）
- 卡片循环播放，右上角始终显示"当前序号 / 总数"
- 卡片内容承载：全屏封面图、类别徽章、查看详情入口、作者信息、标题、两行摘要、标签

设计要点

- 牌堆高度统一控制在 520\~580px，确保无论 PC 还是移动端都能看到背后下一张卡的"悬念感"
- 滑动判定阈值经过反复调校：水平位移超过卡片宽度 25% 即触发滑出，避免误触
- 移动端双模式切换采用胶囊分段控件，符合拇指可达区域设计原则
- 瀑布流模式复用发现页瀑布流组件，降低用户在不同浏览模式间的认知成本

## **二、沉浸式视觉设计**

  --------------------------------------------------------------------
                           **沉浸式视觉设计**

  --------------------------------------------------------------------

功能概览：以"半透明 + 柔和光影 + 圆润卡片"为核心视觉语言，配合明暗双主题切换，营造统一、轻盈且具有高级感的浏览氛围。

核心交互

- 玻璃拟态（Glassmorphism）三件套贯穿全站：玻璃面板、玻璃卡片、玻璃按钮
- 全局主题切换入口：顶部导航栏右侧 + 抽屉菜单底部 + 设置页 Appearance 选项，三处入口实时同步
- 暗色模式变量驱动：所有玻璃容器均提供亮/暗两套配色方案
- 圆角语言统一：卡片大圆角（16\~24px），按钮/标签全圆角胶囊
- 字体组合：正文 Inter（中文 PingFang/微软雅黑回退），标题 Quicksand（中文圆体回退）

设计要点

- 玻璃面板：`rgba(255,255,255,0.72)` + `backdrop-filter: blur(20px)` + 白色半透明描边 + 柔和阴影；暗色下切换为 `rgba(30,41,59,0.65)`
- 玻璃卡片：同上，透明度 0.75、模糊 16px
- 玻璃按钮：透明度 0.55、模糊 12px，hover 时透明度升至 0.85
- 品牌主色：亮色模式 `#0058be → #2170e4` 横向渐变；暗色模式强调色 `#adc6ff`
- 点赞/爱心专用色：`#a43073 → #fc79bd` 渐变
- 动效基调克制：卡片 hover 轻微上浮 4px、图片 hover 缓慢放大 1.05、按钮按压缩小至 95%、Toast 3 秒自动消失

## **三、创作者聊天**

  --------------------------------------------------------------------
                             **创作者聊天**

  --------------------------------------------------------------------

功能概览：在浏览作品的同时，用户可一键进入与创作者的聊天空间。聊天界面支持消息发送、回复状态提示与 AI 辅助回复，让内容浏览从"单向发现"延伸为"双向交流"。

核心交互

- 顶栏展示对方头像、绿色在线点、活跃状态、通话/视频占位按钮
- 消息气泡：我方右侧主色渐变气泡，对方左侧白色气泡，下方时间戳精确到分钟
- 发送反馈：用户发送消息后，对方头像处显示"is typing..."动画指示
- AI 智能回复：调用大模型以创作者人格生成 1\~3 句温暖对话式回复
- AI 降级兜底：AI 节点失败或未配置时，自动回复固定兜底文案，主流程不中断
- 输入栏：附件、表情占位按钮 + 发送按钮（空内容时自动禁用）
- 消息持久化：所有消息写入数据表，刷新页面后历史消息仍在

设计要点

- 单会话场景默认与视觉艺术家/旅行摄影师 Elena Rivera 互动，角色设定温暖、有思想、健谈、友好
- 大模型调用温度参数偏高（≈0.8），鼓励更具个性的表达
- "is typing..." 状态指示时长约 1.5\~3 秒，与真实 AI 推理节奏匹配
- 兜底文案示例："Thanks for your note! I'd love to chat more soon."
- 创意始终是辅助而非替代：AI 仅在用户主动发送消息后触发，避免过度打扰

## **四、灵感收藏**

  --------------------------------------------------------------------
                              **灵感收藏**

  --------------------------------------------------------------------

功能概览：用户可以将喜欢的作品一键收藏，并在个人空间集中查看与管理。支持按内容类型进行筛选，方便用户沉淀属于自己的灵感库。

核心交互

- 卡片与详情页均提供"收藏"按钮：图标实心/空心一键切换，状态在多处实时同步
- 个人空间"关注"页：标题 + 副标题"收藏的帖子与灵感清单"
- 搜索框：实时匹配标题与标签，输入即筛选
- 类别药丸过滤：【All / Architecture / Food & Drink / Travel / Design 等】，与搜索叠加生效
- 收藏卡片样式：左封面缩略图（带类别角标）+ 右侧来源、标题、摘要、标签、删除按钮
- 删除操作：数据表删除后列表即时更新 + Toast 反馈
- 空状态：显示图标 + "暂无关注内容" + 引导文案，避免空白页
- 点击收藏卡片尝试匹配打开对应文章详情

设计要点

- 收藏功能是用户沉淀"灵感库"的核心入口，需要足够轻量 ------ 一键 toggle，无确认弹窗
- 收藏数据按用户维度隔离，每个用户只能看到自己的收藏
- 删除采用即时反馈而非二次确认，降低操作成本，提升用户掌控感
- 搜索 + 类别过滤叠加逻辑遵循"AND"语义，精准缩小结果范围
- 类别角标位于缩略图左上角，使用半透明玻璃质感，与整体设计语言一致

## **五、塔罗式情绪探索**

  --------------------------------------------------------------------
                           **塔罗式情绪探索**

  --------------------------------------------------------------------

功能概览：将传统塔罗的"抽取与解读"机制，转化为现代的情绪探索体验。用户经过简短的呼吸引导后抽取一张专属情绪卡，了解自己的探索欲、创造欲、疲惫感、孤独感等状态，并获得对应的情绪解读与灵感寄语。

核心交互

- 入口：个人主页"灵感日历"上方或抽屉菜单的专属入口
- 呼吸引导阶段：屏幕中央呈现缓慢缩放的光晕圆环，配合"吸气...屏息...呼气..."的文字提示，全程约 15\~20 秒
- 抽卡阶段：圆环逐渐收束为一张翻转的卡片，伴随轻微震动反馈
- 翻牌动画：卡片 3D 翻转约 0.8 秒后揭示内容
- 情绪卡内容：
  - 顶部稀有度徽章（如"灵感卡 SSR / SR / R"）
  - 主标题（一句话情绪洞察）
  - 详细解读（约 80\~120 字的温暖解读文案）
  - 三个相关话题标签（#Lifestyle / #Inspiration 等）
  - 右上角"旅行 / 生活 / 创造"等情绪场景标签
- 后续操作：底部双按钮 ------ "再抽一张"重置流程，"使用这张卡"将该情绪主题带入今日发布

设计要点

- 稀有度机制借鉴抽卡游戏体验，提升"专属感"与社交分享动力
- 呼吸引导节奏与冥想类 App 保持一致（约 4-7-8 节奏），降低焦虑、提升专注
- 情绪卡内容由 AI 节点根据用户近期浏览/发布/收藏的内容动态生成，确保千人千面
- "使用这张卡"作为情绪卡与发布流程的桥梁，把情绪洞察转化为实际创作灵感
- 整个流程不超过 60 秒，保证轻量可重复体验

## **六、灵感热度速览**

  --------------------------------------------------------------------
                            **灵感热度速览**

  --------------------------------------------------------------------

功能概览：用户可在个人主页快速查看自己的灵感热度数据，包括发布数、关注者、关注数等核心指标；同时通过"灵感日历"组件，将 14 周内的创作活跃度以热力图形式直观呈现，让数据既好看又有成就感。

核心交互

- 顶部资料卡：渐变描边圆头像 + 昵称 + handle + 简介 + "Edit Profile" 按钮
- 数据条：Posts / Followers / Following 三项关键指标横向排列
- 灵感日历（核心可视化组件）：近 14 周（约 98 天）每日活跃度热力图
  - 横轴：日期（周一至周日 7 列 × 14 周）
  - 纵轴：星期几
  - 单元格颜色深浅映射当日发布/收藏/点赞的活跃度
  - 顶部"少 ← → 多"图例明确告知映射规则
- 右上角统计：最近 14 周 × 63 天内有收获
- 数据总结：底部"收获 781 个赞 / 创作 40 篇"等核心数据高亮
- 内容 Tab：Posts / Saved / Appreciated，分类查看不同维度的作品

设计要点

- 灵感日历借鉴 GitHub Contribution Graph 的设计语言，但对用户更友好 ------ 用品牌主色蓝（而非绿色），色调与 Muse 整体一致
- 颜色梯度分为 5 档（极浅、浅、中、较深、深），覆盖从"无活动"到"高产创作"的完整区间
- 数据条采用大数字 + 小标签的对比排版，扫一眼即可获得关键信息
- "收获 vs 创作"双指标并列，让用户既看到自己的输出价值，也看到来自社区的认可反馈
- 暗色模式下日历单元格采用蓝色饱和度梯度，而非简单反色，保持视觉质感

## **结语**

Muse 以"美学、灵感、互动"为内核，把传统的单向内容消费升级为"沉浸探索 + 情绪共振 + 创作交流"的完整体验闭环。

后续迭代将围绕：

- 更丰富的 AI 创作辅助能力
- 更细致的情绪与灵感关联模型
- 更开放的创作者生态

持续打磨产品的"美学底色"与"互动温度"。
